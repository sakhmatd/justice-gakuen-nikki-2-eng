# キャラクターは『デンワ』モードで選んで決定します。/メールが来ると到着音が鳴ります。
p1_note: Choose a character in PHONE mode. | A chime plays when mail arrives.

# 左右を表しています。/タイミング良く1回決定ボタンを押すと、将馬が投球します。

p2_a1: Pitch

# 流の飛び込み世界一
p4_title: Nagare's World-Class Dive
# 左右ボタン レベルの選択 / 決定ボタン レベルの決定、着水 / 上下左右ボタン 演技
p4_b1: Left/Right
p4_a1: Choose level
p4_b2: Action
p4_a2: Set level / Entry
p4_b3: D-pad
p4_a3: Moves
# 3回飛び込みをして得点の合計を競います。1回10点満点、合計30点満点です。
p4_body1: Dive 3 times for the best total. Each dive is out of 10, so 30 is perfect.
# 始めにレベルを選択します。レベルが高いほど難しく、もらえるポイントも高く
# なります。まず演技のお手本が出ます。よく覚えてください。
p4_body2: First choose a level. Higher levels are harder but earn more points. | A model dive is shown first. Watch it closely.
# 演技…飛び込み中お手本通りにボタンを入力します/正確に押すほど得点が高く
# なります/着水…水面につくまでに決定ボタンを押します/水面ぎりぎりで押すほど、
# 得点が高くなります
p4_note: Moves: in mid-dive, press the buttons as in the model. The more exact, the higher the score. | Entry: press Action before you hit the water. The closer to the water, the higher the score.
