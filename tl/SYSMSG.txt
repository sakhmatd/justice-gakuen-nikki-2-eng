# 147 of 148 strings are identical here (topic sysmsg). Pointer tables:
# exe 0x80090580 and NEWOPT 0x800a2b90 (a second copy of the pool).
# One string = one grid row (24 cells). {sp} = blank cell 0xfff.
# Titles (s037 s042 s062-064 s090) use 40x40 glyphs: one glyph per
# two cells. s008 and s127-s138 point to s000. Usage and widths:
# data/sysmsg_use.tsv. ー is code 0x071.
