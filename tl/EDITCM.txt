# EDIT command-list cards (DAT2/EDITCM.BIZ, 32 entries), built by tools/build_editcm.py.
# cmNN = archive entry NN-1 = EDIT style NN. Entries 1-24 derive from the
# first game's EDITCM01-24 (same numbering); rows that match the first
# game's card pixel for pixel carry its EN (topic editchar). An empty value
# means the row changed or is new: the card stays JP until all its rows
# have EN. Notes (.ann) must be checked for rows marked "cmd changed".
# ID: EN text. '|' forces a line break; otherwise the builder fits one line
# and falls back to two lines when the row has room.
# cmNN.sK = special move row K (必殺技 cell, top to bottom),
# cmNN.bK = Burning Vigor Attack row K (完全燃焼アタック cell).
# cmNN.sK.ann / .bK.ann = red text notes in the command column of that row,
# left to right, separated by '|': 空中で = Air, ため = hold, 連打 = mash,
# 連続入力可 = repeatable, 後 = '>' (fighting-game notation for "then"; the
# gap is one glyph wide). The 空中可 badge is not listed (always ann.badge).
# Names: official Western (Rival Schools) names from moves.pdf, matched
# by character and command (work/re/moves/mapping.org); EDIT variants
# reuse the official base name. "?" = no official match.
